# Skill icons

Color SVG icons from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), distributed under the included [MIT license](LICENSE).

Each SVG is the unmodified `icons/<name>/<name>-original.svg` file, saved locally as `<name>.svg`. The icons retain their original brand colors in both light and dark mode. Brand names and logos belong to their respective owners.
